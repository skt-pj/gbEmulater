# 要件定義 0.1.0

REQ-01: Android端末から`.gb` ROMを選択できること。
REQ-02: 初代Game BoyのCPU命令、メモリ、割り込み、タイマーを実行できること。
REQ-03: 160x144のDMG映像を描画できること。
REQ-04: D-pad、A、B、START、SELECTをマルチタッチ入力できること。
REQ-05: ROM only、MBC1、MBC3、MBC5のROM bankingを扱えること。
REQ-06: Pixel 10aのAndroid 16でインストール可能なtargetSdk 36 APKを生成できること。
REQ-07: 配布release APKは共通署名を使い、SHA-256と署名証明書をCIで検証できること。
REQ-08: ROMをアプリへ同梱しないこと。
